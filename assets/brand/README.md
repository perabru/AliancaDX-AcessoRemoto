# AliançaDX — assets web

Pack leve derivado da marca 6.2.0. A imagem original e seu lettering foram
preservados; nenhum arquivo do aplicativo foi alterado.

| Arquivo | Uso |
| --- | --- |
| `aliancadx-logo.png` | Logo horizontal sobre branco, 402 × 94 |
| `aliancadx-logo-original.jpg` | Original intacto, 402 × 94 |
| `brand.json` | Paleta e procedência originais |
| `aliancadx-app.svg` | Símbolo vetorial no enquadramento do app |
| `favicon.svg` | Símbolo com enquadramento maior para tamanhos pequenos |
| `icon-16.png`, `icon-32.png` | Favicons PNG |
| `apple-touch-icon.png` | Ícone 180 × 180 |
| `icon-192.png`, `icon-512.png` | Ícones quadrados para uso web |
| `og-image.svg`, `og-image.png` | Prévia social 1200 × 630 |

Para Open Graph, prefira `og-image.png`, pois nem todos os consumidores
aceitam SVG. A página deve resolver os caminhos conforme sua implantação.
O pack não adiciona hospedagem, manifesto, HTML ou metadados por conta própria.

O SVG social é um layout vetorial com o JPEG original embutido. Os PNGs foram
renderizados localmente pelo Inkscape e otimizados sem perdas. Os arquivos de
logo, a paleta e o SVG do app são cópias byte a byte do pack original.

SHA256 do JPEG original:
`f645462fab70ea57c76a051a38053e56ee0a36438dfdaa9f3464f0fcc3b1f92a`.

A imagem foi fornecida pelo usuário; seus direitos e os da marca permanecem
com os respectivos titulares. Não há fonte externa nem selo de aprovação ou
certificação incluído neste pack.
