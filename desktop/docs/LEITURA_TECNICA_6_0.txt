MINIANYDESK DESKTOP 6.0.0 — INTERNET SEM CONTA DE VPN
Dois programas Python: Host e Controlador • Windows 10/11 x64

COMECE AQUI
1. No computador que será acessado, execute dist/MiniAnyDesk_Host_Setup.exe.
2. No computador que acessará, execute dist/MiniAnyDesk_Controlador_Setup.exe.
3. Abra o Host e deixe-o disponível. Ele prepara a rede privada e mostra
   um código de pareamento. Copie esse código e envie-o à pessoa autorizada,
   junto da senha atual de acesso, por um canal de sua confiança.
4. No Controlador, escolha o acesso pela internet, cole o código do Host,
   informe a senha e conecte. Aguarde a aprovação no computador remoto.
5. Mantenha os dois programas abertos e os computadores ligados à internet.

Não é necessário criar conta de VPN, fazer login no navegador, configurar
IP virtual, alterar o roteador ou hospedar um site. Os componentes Python,
bibliotecas e EasyTier acompanham os instaladores. O código de pareamento
é privado: ele permite participar da rede desse Host. A senha de acesso
remoto e a aprovação local continuam exigidas em cada nova sessão.

A REDE INTEGRADA
EasyTier 2.6.4 cria uma rede privada por Host. A preparação é automática.
As aplicações usam o modo no-TUN: o tráfego do MiniAnyDesk atravessa a rede
virtual em espaço de usuário, sem criar adaptador VPN no Windows. Não se
trata de uma VPN que encaminha toda a navegação do computador.

Os computadores procuram conexão direta entre si. Se ela não for possível,
podem usar nós públicos compartilhados para retransmitir os dados. O pacote
configura caminhos TCP e WSS/443. Esses serviços são operados por terceiros;
a disponibilidade, a latência e a banda não são garantidas por este projeto.
A alternativa TCP e o caminho WSS não representam necessariamente dois
operadores independentes. Nenhum servidor próprio foi implantado por esta
entrega. Uma rede que bloqueie todos os caminhos de saída pode impedir o
acesso. Uma conexão local funcionando não comprova acesso pela internet.

A camada TLS do MiniAnyDesk permanece entre Host e Controlador, inclusive
quando há retransmissão. O código inclui a identidade do certificado do
Host; ela é conferida antes de enviar a senha. O retransmissor não termina
essa sessão TLS. Não há rede universal nem senha de VPN compartilhada por
todos os usuários. As regras da rede integrada limitam a entrada à porta do
Host e impedem utilizar o computador como retransmissor de redes estranhas.
Não são publicados serviços de pasta, área de trabalho ou administração do
Windows. O programa não altera DNS nem instala um serviço de inicialização.

DADOS, NOMES E STATUS
Os cadastros de computadores e seus nomes continuam editáveis. O endereço
local temporário do túnel não substitui a identidade de um Host salvo.
No acesso pela internet, disponibilidade exige um caminho de rede válido;
conectividade com um retransmissor, sozinha, não significa que o Host esteja
aberto ou que uma sessão remota tenha sido autorizada.

O código é usado em memória por padrão. A opção de lembrá-lo é explícita;
no Windows, o armazenamento utiliza proteção vinculada ao usuário local.
Não inclua códigos, senhas ou chaves privadas em repositórios ou chamados.
Fechar o aplicativo encerra seu próprio processo de rede. Isso não remove
nem desliga uma VPN instalada por outra aplicação no computador.

FUNÇÕES MANTIDAS
- Senha temporária de oito números ou senha personalizada; Mostrar/Ocultar.
- Certificado persistente, aprovação local e botão para encerrar a sessão.
- Nome dos computadores, edição dos cadastros e consulta de disponibilidade.
- Visualização da tela, escolha de monitor, tela cheia, mouse e teclado.
- Pausa local e liberação de teclas e botões ao encerrar.
- Envio de arquivos nos dois sentidos, com escolha e aprovação do destino.

Cada arquivo tem limite de 100 MiB e verificação SHA-256. Arquivos parciais
são descartados em uma interrupção. Comandos e arquivos de uma sessão antiga
não são repetidos depois da reconexão. A recuperação de uma sessão exige
o mesmo certificado e uma nova aprovação local no Host.

ACESSO NA MESMA REDE
O acesso manual por IPv4/nome e porta continua disponível como opção local.
A porta padrão é 64321. Endereços 169.254 são endereços de alcance local;
não devem ser usados como endereço de acesso pela internet. O fluxo pelo
código de pareamento não depende de descobrir o IP físico correto do Host.

INSTALAÇÃO E ATUALIZAÇÃO
Os dois executáveis instalam por usuário. Python 3.12.10 x64 e as bibliotecas
estão incluídos para instalação offline. A comunicação entre computadores
requer internet. Não é necessário instalar separadamente uma VPN ou driver
de captura para o fluxo no-TUN. Os EXEs não são assinados comercialmente;
esta entrega não suprime avisos de reputação ou proteções do Windows.

Feche versões anteriores antes de atualizar. Os dados de usuário existentes
ficam fora da pasta instalada e são preservados. A rede usada pelas versões
anteriores não é removida: se não for mais necessária, sua remoção pode ser
feita pelos mecanismos normais do Windows, considerando outros aplicativos.
O Host só fica disponível enquanto aberto, conforme a preferência visível;
nenhum acesso é aprovado automaticamente. Não há inicialização oculta com
Windows. Os APKs Android não fazem parte desta atualização.

SE NÃO CONECTAR
Confira que o Host está aberto/disponível, os dois PCs têm internet e o
código pertence ao Host atual. Se a porta ou identidade mudar, copie o novo
código. Confira também a senha atual e aceite o pedido no computador remoto.
Aguarde a preparação da rede; não confunda 'aguardando Host' com sessão ativa.

Firewall, proxy obrigatório, inspeção TLS, suspensão, falta de energia,
indisponibilidade dos retransmissores ou bloqueios do provedor podem impedir
ou interromper o acesso. Solicite ao responsável pela rede a liberação dos
caminhos necessários. Não desative antivírus ou firewall para instalar.
Nenhum programa pode garantir comunicação permanente nessas condições.

FONTES E RECONSTRUÇÃO
Os fontes Python, testes, Python oficial, wheelhouse, runtime EasyTier e
avisos de licença acompanham o ZIP. Com Python 3.11/3.12 x64 e Tcl/Tk, use
instalar_host.py ou instalar_controlador.py para instalar pelos fontes.
installer/REBUILD.txt explica como reconstruir os executáveis.
VALIDACAO.txt separa o que foi testado das etapas ainda não comprovadas.
SHA256.txt identifica os artefatos desta edição.
